# MK Race Engineer

**Your AI voice race engineer for sim racing.**

Hold a push-to-talk button, ask a question, and get an answer over a TV-style radio voice: fuel, gaps, pace, pit stops, or anything else. MK Race Engineer reads live telemetry and uses the AI model you choose.

Currently available for **Le Mans Ultimate**. More simulators are planned.

## Features

- Push-to-talk voice assistant with a radio-style voice
- Live telemetry: fuel, gaps, pace, pit stops, multiclass traffic
- Free conversation: ask anything, even off-topic
- Bring your own AI: use the provider you already have, with automatic fallback to a backup
- Setup reading and advice from the pits
- Hotkeys and Stream Deck support
- Languages: English, Italian, Spanish

A **Free** version is included, and **Pro** unlocks the full feature set. Details and plans: https://mkraceengineer.com
